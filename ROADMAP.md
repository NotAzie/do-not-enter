# Roadmap

This document outlines the planned direction for DO NOT ENTER.

## Vision

DO NOT ENTER is an immersive, adaptive horror experience that uses web technologies to create genuine feelings of fear, paranoia, and unease. The goal is to push the boundaries of what's possible in a browser-based horror experience while maintaining user safety and respect.

## Guiding Principles

1. **Psychological Over Visual**: True horror is in the mind, not just jump scares
2. **Adaptive Experience**: The horror should respond to the user's behavior
3. **Respect User Boundaries**: Terrify, don't traumatize
4. **Atmospheric Consistency**: All elements should feel part of the same world
5. **Accessibility**: Horror should be adjustable for different sensitivity levels

## Phase 1: Foundation (Current - Version 1.0)

**Status**: Released

- [x] Basic horror engine with horror level system
- [x] Ambient audio and whisper system
- [x] Visual distortion effects (static, shadows, faces)
- [x] Paranoia mode with text replacement
- [x] Fake notifications and psychological tricks
- [x] Three entity profiles (SCP-style)
- [x] Experiment logs
- [x] Basic responsive design
- [x] Content warnings and safety guidelines

**Goals**:
- Working, atmospheric horror experience
- Multiple interactive systems that build tension
- Safe, respectful approach to horror
