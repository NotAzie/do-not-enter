# Screenshots Placeholder

This directory is reserved for project screenshots.

## To Add Screenshots

1. Take screenshots of the application
2. Save as PNG files in this directory
3. Name descriptively (e.g., `banner.png`, `entity-view.png`)
4. Update README.md to reference actual screenshots

## Suggested Screenshots

- **Banner**: Full-width screenshot of the hero/landing section
- **Entity Document**: Screenshot of an SCP-style entity profile
- **Effects**: Screenshot showing visual effects active
- **Mobile**: Screenshot of mobile layout
