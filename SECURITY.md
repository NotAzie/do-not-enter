# Security and Content Warnings

## Content Warnings

**PLEASE READ BEFORE USING THIS APPLICATION**

DO NOT ENTER is a horror-themed interactive experience that uses various techniques to create feelings of fear, paranoia, and unease. By using this application, you acknowledge that you may experience:

### Psychological Effects

- Feelings of being watched or followed
- Paranoia and anxiety
- Disturbing thoughts or images
- Sleep disruption (if used before bedtime)
- Increased heart rate or physiological stress responses

### Audio Content

- Sudden loud noises
- Whispered messages (may seem like they're in the room with you)
- Ambient unsettling sounds
- Speech synthesis used for eerie messages

### Visual Content

- Dark, atmospheric imagery
- Content may be disturbing to some viewers
- Flashing or flickering effects (may trigger photosensitivity)
- Imagery designed to create unease

### Who Should Avoid This Experience

- Individuals with anxiety disorders or panic disorders
- Those with a history of trauma or PTSD
- People with photosensitive epilepsy or seizure disorders
- Anyone currently experiencing high stress or emotional vulnerability
- Young children or individuals not comfortable with horror content
- Anyone who has been advised to avoid horror content for health reasons

### If You Experience Distress

If you experience significant distress while using this application:

1. **Close the browser tab immediately** - you don't need to interact with anything
2. **Take a break** - step away from the computer
3. **Ground yourself** - remind yourself this is fictional content
4. **Seek support** - talk to someone if you're struggling
5. **Return to comfort content** - do something that makes you feel safe

### Emergency Resources

If you are experiencing a mental health crisis:
- **US**: Call or text 988 (Suicide & Crisis Lifeline)
- **UK**: Call 111 or contact Samaritans at 116 123
- **International**: Search for local crisis resources
- **Emergency**: Call your local emergency number

## Technical Security

### No Data Collection

DO NOT ENTER does **NOT** collect, transmit, or store your personal data outside of your browser:

- Your name (if provided) is stored only in your browser's localStorage
- Visit history is stored only in your browser's localStorage
- No data is sent to any server
- No tracking or analytics are used

### Browser Permissions

The application may request:

- **Audio context**: Required for ambient sounds and whispers (you must interact with the page first due to browser autoplay policies)
- **Speech synthesis**: Used for whisper messages (requires browser permission)
- **Device orientation/motion**: Optional, for mobile effects (requires permission)

All permissions are optional and the experience will work without them.

### JavaScript Requirements

This application requires JavaScript to function. It will not work if JavaScript is disabled.

### Browser Compatibility

The application uses modern web APIs and may not work on:
- Very old browsers
- Browsers with strict security settings
- Browsers with JavaScript disabled

### Known Technical Considerations

- Some effects rely on timing and may behave differently across browsers
- Audio features require user interaction before they can start (browser policy)
- Mobile devices may have limited support for some effects
- Performance may vary based on device capabilities

## Safe Usage Guidelines

### Environment

- Use in a comfortable, safe environment
- Consider using during daytime hours for first experience
- Ensure you have control over your environment

### Duration

- Take breaks during extended use
- Don't use right before sleep if you're sensitive
- Stop if you start feeling uncomfortable

### Accessibility

If you have accessibility needs:
- Consider using browser extensions to reduce motion/animations
- Disable audio if you're sensitive to sound
- Use a screen reader friendly browser if needed (though the visual experience is central)

### Children and Minors

This content is not suitable for young children. Parents and guardians should:
- Review the content before allowing children to view
- Consider the child's maturity and sensitivity
- Supervise use if appropriate
- Be prepared to help the child process the experience
